# Connect and prove

The services run. Now name the URLs your app will use, and prove each service is reachable.

## Name the connection URLs

Your app reaches these by URL. Add two environment variables to your `.env` file now — you'll wire them into real, *validated* config in Chapter 6 (we're only naming them here):

```
# .env  (git-ignored since Chapter 4)
DATABASE_URL=postgresql://portal:localdevpw@localhost:5432/jobportal
REDIS_URL=redis://localhost:6379
```

The host is `localhost` because you mapped the containers' ports out to your laptop. (Once your app *itself* runs inside Docker — a deployment concern for Chapter 65 — services address each other by *service name* on Docker's internal network instead. File that away; it's a classic point of confusion.)

## Prove both are reachable

First load the URLs into your shell (the checks below read them as variables), then run the two probes:

```
set -a; source .env; set +a            # export every var defined in .env into this shell
psql "$DATABASE_URL" -c "SELECT 1;"     # → returns 1
redis-cli -u "$REDIS_URL" ping          # → PONG
```

> 💡 **Hint — two gotchas.** If `up` complains a **port is already in use**, something (often a native install from a past project) holds `5432`/`6379` — stop it, or map a different host port like `"5433:5432"` and update `DATABASE_URL`. If `psql` says **connection refused** right after `up`, the container is probably still starting — wait a moment and retry; this is the exact race a healthcheck removes when you automate startup later.

## The picture

```
 Your machine (host)
 ┌──────────────────────────────────────────────────────┐

```

## Keep the secret out of Git

Make sure `.env` is in your `.gitignore` (you added it in Chapter 4) — those connection strings carry a password and must never reach Git.

```
git check-ignore .env       # → prints ".env" if it's ignored (good)
```

✅ **Do** confirm `.env` is ignored before you commit anything today.
❌ **Don't** paste a real connection string into committed code or a tracked file.

**Verify:** two green checks — `SELECT 1;` returns `1`, `redis-cli ping` returns `PONG`. Your foundation is real.

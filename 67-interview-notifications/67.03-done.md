## Quiz

1. After this change, `scheduleInterview` does three things in order: INSERT into interviews,
   queue.add, return the interview object. What is the consequence if `queue.add` succeeds but
   the database INSERT had already failed (and the function threw before reaching queue.add)?
   Is there a risk of a "ghost job" — a job in the queue for an interview that does not exist
   in the database?

2. The worker receives `scheduledAt` as an ISO string like `"2026-07-01T10:00:00.000Z"`. The
   `sendInterviewNotification` function in mailer.ts was originally written to accept a `Date`
   object. What TypeScript change would you make to `sendInterviewNotification` to accept both
   string and Date, and how would you format the date in the email body?

3. A recruiter schedules two interviews for the same applicant on the same job within 5 seconds.
   Both requests succeed and both notification jobs are enqueued. The applicant receives two
   emails. Is this the correct behaviour? If not, what change to the queue.add call or the
   worker handler would prevent the duplicate notification?

# Guidelines for this chapter

A quick frame before the decisions start — read it, then dive in.

**Revise coming in.** This chapter only assumes you can *read* basic SQL (a `SELECT … WHERE`) and basic JS/TS (a function with typed arguments). Nothing here is something the course teaches from scratch — if either feels rusty, a five-minute skim is enough.

**Keep it yours.** These tools are the same whatever you build — but the *project* is yours: its name, and a stack you'll live with for the rest of the build.

**Daily working guidelines.** No feature ships today, but you still touch the repo (you record your stack in the `learning-log/`), so: make a clean commit by end of day, and glance that nothing secret slipped past `.gitignore`. And carry one question as you read — it's the cost this chapter is really about: **the tool you pick here you live with for 60+ chapters; what does it cost you to swap it out in week 3, mid-build?** Hold that thought — it's why "boring and understood" beats "new and shiny."

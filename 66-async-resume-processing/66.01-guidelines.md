# Chapter 66 — Async Résumé Processing

## What you will build

After a résumé is uploaded to S3 (Chapter 48), enqueue a background job that downloads the
file, counts the words in the raw bytes, and stores the result in the database. This models
the pattern used for real résumé parsing (PDF extraction, keyword indexing) without requiring
a heavy PDF library.

## Learning goals

- Enqueue a job from the résumé upload route
- Download a file from S3 inside a worker handler using `GetObjectCommand`
- Run a database migration to add a computed column to an existing table
- Observe the end-to-end async file processing cycle

## Prerequisites

- Chapter 48: S3 upload working, `resumes` table in place
- Chapter 63–64: queue and worker in place
- `src/shared/s3.ts` exports an S3 client (from Chapter 48)

## Implementation

### src/worker/handlers/processResume.ts

```ts
import { GetObjectCommand } from '@aws-sdk/client-s3';
import { Readable } from 'stream';
import s3 from '../../shared/s3';
import db from '../../shared/db';
import config from '../../shared/config';

// Download file from S3, count words, store in DB
export async function processResume(resumeId: string, s3Key: string): Promise<void> {
  // Download the file from S3
  const command = new GetObjectCommand({
    Bucket: config.S3_BUCKET,
    Key: s3Key,
  });
  const response = await s3.send(command);

  // Stream body to a buffer
  const stream = response.Body as Readable;
  const chunks: Buffer[] = [];
  for await (const chunk of stream) {
    chunks.push(typeof chunk === 'string' ? Buffer.from(chunk) : chunk);
  }
  const buffer = Buffer.concat(chunks);

  // Word count: split the raw text on whitespace
  // For a real parser, use pdf-parse or similar — this is a stand-in
  const text = buffer.toString('utf-8', 0, Math.min(buffer.length, 100_000));
  const wordCount = text.split(/\s+/).filter(Boolean).length;

  // Write back to the database
  await db.query(
    `UPDATE resumes SET word_count = $1 WHERE id = $2`,
    [wordCount, resumeId]
  );
}
```

## Verifying the word count

After uploading a résumé and waiting for the worker:

```bash
psql $DATABASE_URL -c \
  "SELECT id, s3_key, word_count FROM resumes ORDER BY created_at DESC LIMIT 1;"
```

`word_count` should be non-null and greater than 0.

---

## Note on PDF parsing

The word count from raw bytes is a rough proxy. For a real PDF résumé:
- Binary PDF content contains mostly non-text bytes, so the count will be low
- `pdf-parse` (npm) extracts actual text from PDF binary correctly
- The pattern here — download from S3, extract content, write to DB — is identical whether
  you use raw bytes or `pdf-parse`

Adding real PDF parsing is a straightforward swap of the extraction step.

## 6. Owner changes a member's role

Get a non-owner recruiter ID from the member list:

```bash
MEMBER_ID=$(curl -s \
  -H "Authorization: Bearer $OWNER_TOKEN" \
  http://localhost:3000/api/companies/members \
  | jq -r '.members[] | select(.companyRole != "owner") | .recruiterId' | head -1)

curl -s -X PATCH \
  http://localhost:3000/api/companies/members/$MEMBER_ID \
  -H "Authorization: Bearer $OWNER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"role":"recruiter"}' \
  | jq .
```

Expected: `{ "message": "Role updated." }` with HTTP `200`.

Verify in psql:

```bash
psql $DATABASE_URL -c \
  "SELECT company_role FROM recruiters WHERE id = '$MEMBER_ID';"
```

Expected: `recruiter`

Compare the array approach and the graph approach on: ease of adding a new stage that branches (e.g., both 'offer' and 'reference_check' are valid next steps from 'final_interview'), and the code needed to validate a transition.

A developer argues it should throw `ConflictError` (409) because the issue is a state conflict — the application is already in a state that makes the requested transition invalid, which is closer to a conflict than a bad request.

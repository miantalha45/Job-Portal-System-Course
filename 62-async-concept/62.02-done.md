## Quiz

1. A system returns HTTP 201 to the user after saving to the database but before calling
   `queue.add`. The worker is down for 30 minutes. What happens to the background work that
   should have been queued during that window, and how does enqueuing before returning the
   response change this outcome?

2. BullMQ uses Redis sorted sets to track job state. Each job has a score (the timestamp at
   which it becomes eligible to run). Explain how this data structure naturally supports delayed
   jobs — jobs that should not run until a specific time in the future.

3. A team debates whether to use BullMQ (Redis-backed queue) or a PostgreSQL-backed job queue
   (a `jobs` table with a worker that polls it). List two advantages of the Redis approach and
   two advantages of the PostgreSQL approach for a system like this job portal.

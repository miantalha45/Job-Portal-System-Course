# Chapter 59 — Definition of Done

## Verifiable checklist

Run every command and confirm the expected result before marking this chapter complete.

```bash
# 1. Compile with zero TypeScript errors
npx tsc --noEmit

# 2. Promote a user to admin role in the database
psql $DATABASE_URL -c "UPDATE users SET role = 'admin' WHERE email = 'admin@example.com';"

# 3. Obtain an admin JWT
TOKEN=$(curl -s -X POST http://localhost:3000/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"email":"admin@example.com","password":"Secret123!"}' \
  | jq -r '.accessToken')

# 4. List all companies — expect JSON array
curl -s -H "Authorization: Bearer $TOKEN" \
  "http://localhost:3000/api/admin/companies" | jq '.companies | length'

# 5. List only pending companies — expect only pending rows
curl -s -H "Authorization: Bearer $TOKEN" \
  "http://localhost:3000/api/admin/companies?status=pending" \
  | jq '[.companies[].status] | unique'
# Expected: ["pending"]

# 6. Verify a company (replace <COMPANY_ID> with a real id from step 4)
curl -s -X PATCH -H "Authorization: Bearer $TOKEN" \
  "http://localhost:3000/api/admin/companies/<COMPANY_ID>/verify" \
  | jq '.company.status'
# Expected: "verified"

# 7. Try to verify the same company again — expect 409
curl -s -o /dev/null -w "%{http_code}" -X PATCH \
  -H "Authorization: Bearer $TOKEN" \
  "http://localhost:3000/api/admin/companies/<COMPANY_ID>/verify"
# Expected: 409

# 8. Suspend the company
curl -s -X PATCH -H "Authorization: Bearer $TOKEN" \
  "http://localhost:3000/api/admin/companies/<COMPANY_ID>/suspend" \
  | jq '.company.status'
# Expected: "suspended"

# 9. Confirm that all open jobs for that company are now closed
psql $DATABASE_URL -c \
  "SELECT status, count(*) FROM jobs WHERE company_id = '<COMPANY_ID>' GROUP BY status;"
# Expected: no row with status = 'open'

# 10. Confirm that the public cache key was deleted
redis-cli DEL jobs:public:page1
# (DEL returns 0 if key was already gone — that is fine; it confirms the key no longer exists)

# 11. Verify 403 when a non-admin calls the route
NON_ADMIN_TOKEN=$(curl -s -X POST http://localhost:3000/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"email":"recruiter@example.com","password":"Secret123!"}' \
  | jq -r '.accessToken')
curl -s -o /dev/null -w "%{http_code}" -X PATCH \
  -H "Authorization: Bearer $NON_ADMIN_TOKEN" \
  "http://localhost:3000/api/admin/companies/<COMPANY_ID>/verify"
# Expected: 403

# 12. Verify 404 for a non-existent company
curl -s -o /dev/null -w "%{http_code}" -X PATCH \
  -H "Authorization: Bearer $TOKEN" \
  "http://localhost:3000/api/admin/companies/00000000-0000-0000-0000-000000000000/verify"
# Expected: 404
```

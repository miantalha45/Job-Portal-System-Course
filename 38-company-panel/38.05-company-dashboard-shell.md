# 38.05 — Company Dashboard Shell

Create a protected company layout with a page heading, company context, navigation to jobs and members, and an obvious sign-out action. The layout uses the trusted session helper from Chapter 4A; it does not decode a client-provided role as an authorization decision.

Mark the current navigation item, make the menu work at narrow widths, and provide a skip link to the main content.

# 38.10 — Company-Page States

Add consistent feedback across jobs and members:

| State | Example message |
|---|---|
| Empty | Create the company’s first job or invite its first member |
| Loading | Identify the list or action loading |
| Error | State that data could not be loaded and offer retry |
| Forbidden | Direct the user to an allowed dashboard without exposing private data |

Use role checks for user experience but rely on Chapters 25–30 for real enforcement.

Continue with [38.11 — Verify the company dashboard](38.11-company-dashboard-check.md).

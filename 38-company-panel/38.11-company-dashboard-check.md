# 38.11 — Verify the Company Dashboard

Test with an owner, a lower-privilege company member, and an unrelated user:

1. Create, edit, and change a job’s lifecycle state.
2. Visit the jobs list and detail directly by URL.
3. Invite or manage a member using only actions the current role can access.
4. Attempt the same URLs as the unrelated user.
5. Repeat the main flow at a phone width and by keyboard.

# 38.07 — Company Job Form UI

Build one accessible form model that supports the create and edit contracts from Chapter 36. Group related fields, label all controls, and preserve entered values when validation fails.

Differentiate “save draft” from “publish” if the API models both. A pending action must state which operation is running, and a success state should lead to the authoritative refreshed job view.

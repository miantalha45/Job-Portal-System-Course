## 2. Create an applicant profile

```bash
APPLICANT_TOKEN="<access token for a verified applicant account>"

curl -s -X POST http://localhost:3000/api/applicants/profile \
  -H "Authorization: Bearer $APPLICANT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"headline":"Full-stack engineer","bio":"Five years building web apps.","skills":["TypeScript","PostgreSQL"]}' \
  | jq .
```

Expected: HTTP 201, response body contains `id`, `user_id`, `headline`, `bio`, `skills` (array), `created_at`.

Compare these two approaches on: number of database round-trips, correctness in concurrent update scenarios (two clients patching different fields simultaneously), and implementation complexity.

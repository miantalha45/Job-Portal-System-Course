# Use Next.js route handlers for browser mutations

For a browser form that must call an authenticated Express endpoint, create a matching Next.js route handler under `app/api/`. The handler reads the `httpOnly` cookie on the server, forwards the request to Express with the Bearer token, and returns the safe result to the browser.

This keeps tokens out of browser JavaScript and gives the browser one same-origin API surface. Start with the login handler; later job, shortlist, and résumé-upload handlers follow the same pattern.

Do not duplicate Express business logic in these handlers. They are a narrow forwarding layer.

# The UI journey

The browser talks to Next.js. Next.js renders pages, protects dashboard routes, and calls the Express API on the server. Express remains responsible for validation, authorization, and PostgreSQL.

```text
Browser → Next.js page or route handler → Express API → PostgreSQL
```

Build the visible shell first, then public pages, then authenticated dashboard pages, then forms. Do not start with a dense application table before the learner has navigation and a page layout to put it in.

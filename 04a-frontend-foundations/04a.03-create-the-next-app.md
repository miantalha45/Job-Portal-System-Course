# Create the Next.js application

Create a `frontend/` directory beside the Express project and initialise a TypeScript Next.js App Router project inside it. Use the current stable Next.js setup command and choose the App Router, TypeScript, and a simple CSS approach.

Verify that `frontend/` contains `app/`, `public/`, `package.json`, and the development script. Run the frontend in its own terminal and confirm the starter page opens before changing it.

✅ Keep the frontend as its own app.
❌ Do not move the Express API into Next.js route handlers; the course deliberately keeps the API separate.

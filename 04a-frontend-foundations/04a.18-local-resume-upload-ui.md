# Prepare the résumé upload UI

Create a client upload component with an accessible PDF file input, file-size guidance, selected-file feedback, upload progress or pending state, and a result message. Submit the upload through the Next.js proxy route or uploader endpoint chosen in Chapter 48.

Do not expose storage paths or attempt direct storage access from Next.js. The backend validates the file and owns the storage decision.

Verify the UI rejects an obvious non-PDF before submission and displays the backend error if the API rejects it.

# Connect login to secure cookies

Build a login page with email and password fields. Submit it to the Next.js login route handler, which forwards credentials to Express. On a successful response, store access and refresh tokens in secure `httpOnly` cookies and redirect to the appropriate dashboard.

Show a clear invalid-credentials error without revealing which credential was wrong. The browser must never write either token to `localStorage` or `sessionStorage`.

Verify login by refreshing the dashboard page: the session should still be available because the server can read the cookie.

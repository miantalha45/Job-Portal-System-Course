# Describe the data the UI receives

Create TypeScript types in `frontend/types/` for the response shapes the frontend renders: public job card, job detail, current user, company member, applicant profile, application, and API error.

These types are a frontend contract, not a replacement for Express validation. Keep their field names aligned with the JSON returned by the API. When a page needs a new field, update the API contract deliberately rather than using `any`.

Verify a job-card component can be rendered from a typed fixture before making a network request.

# Make forms usable

Build one reusable form pattern: visible labels, required-field indicators, help text, an inline field-error area, a submit button that becomes unavailable while submitting, and a clear success/failure outcome.

Browser validation improves feedback, but Express and Zod remain authoritative. When Express returns a validation error, map its field details to the matching control; display a general error when there is no matching field.

Test invalid input, a server validation error, a network failure, and a successful submission.

# Check the interface on real screens

Make the public navigation, dashboard sidebar, tables, and forms usable on a narrow phone-sized viewport and a wider desktop viewport. Tables may scroll horizontally; do not shrink text until it becomes unreadable.

Check labels, focus visibility, keyboard navigation, colour contrast, descriptive button text, and status text. These are core interface behaviour, not late polish.

Use browser responsive mode and navigate the public page, one dashboard page, and one form without a mouse.

# Give the frontend a shape

Create a feature-oriented frontend structure:

```text
frontend/
  app/                 pages, layouts, route handlers
  components/          small shared visual pieces
  features/            jobs, company, applicant, admin
  lib/                 API client and shared helpers
  types/               API response types
```

Do not make one enormous `components/` folder full of unrelated dashboard code. A job-card component belongs near the jobs feature; only genuinely reusable controls belong in `components/`.

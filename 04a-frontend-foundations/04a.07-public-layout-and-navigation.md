# Build the public shell

Create the root layout and a public navigation bar. It should provide the portal name, a link to browse jobs, and clear login/register actions. Keep the home page small: a heading, one sentence about the portal, and a prominent link to jobs.

Use semantic landmarks—`header`, `nav`, `main`, and `footer`—before worrying about decoration. Verify keyboard users can tab through the navigation in a sensible order.

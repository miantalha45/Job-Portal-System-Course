# Add one server-side API helper

Create `frontend/lib/api.ts` with one helper responsible for calling Express from Next.js server code. It should know the backend base URL, send JSON when appropriate, attach an access token when one is available, and convert non-success responses into a predictable frontend error.

Pages must call this helper instead of scattering `fetch` calls and URL strings throughout the app. Keep it small; do not invent a client-side state library yet.

Verify it can request the public jobs endpoint from a server component.

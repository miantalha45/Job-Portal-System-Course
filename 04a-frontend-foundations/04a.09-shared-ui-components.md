# Create the shared UI pieces

Create small, presentational components for buttons, inputs, badges, cards, page headings, empty states, and error messages. Each should accept data and callbacks through props; none should query the API directly.

Use one status-badge map for job status and one for application stages. Give every status both text and colour so colour is never the only meaning.

Do not create a component merely because a `div` exists once. Reuse should be real, not ceremonial.

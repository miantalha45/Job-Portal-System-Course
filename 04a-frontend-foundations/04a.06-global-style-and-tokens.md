# Establish a small visual system

Create global styles and define a tiny set of visual decisions: page background, readable text colour, accent colour, spacing scale, border radius, and font sizes. Use CSS variables or your chosen styling tool's equivalent.

Build only a small set of reusable visual patterns: primary button, secondary button, text input, select, status badge, card, table, and empty-state message. These patterns stop the three panels from looking like unrelated products.

Verify with a plain sample page before wiring real API data.

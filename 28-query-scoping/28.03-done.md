## 2. Recruiter can fetch their own company

Log in as a recruiter and capture the token:

```bash
RECRUITER_TOKEN=$(curl -s -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"recruiter@example.com","password":"yourpassword"}' \
  | jq -r '.accessToken')
```

Call the `/me` endpoint:

```bash
curl -s \
  -H "Authorization: Bearer $RECRUITER_TOKEN" \
  http://localhost:3000/api/companies/me
```

Expected: `200` with a JSON body containing `id`, `name`, and `status`. Example:

```json
{
  "id": "c-456...",
  "name": "Acme Corp",
  "status": "verified"
}
```

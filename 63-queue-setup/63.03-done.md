# Chapter 63 — Definition of Done

## Verifiable checklist

```bash
# 1. BullMQ is installed
cat package.json | grep bullmq
# Expected: "bullmq": "<version>"

# 2. TypeScript compiles with zero errors
npx tsc --noEmit

# 3. Worker process starts successfully
npm run worker &
WORKER_PID=$!
sleep 2
# Expected: "[worker] Worker started and listening for jobs..."
kill $WORKER_PID

# 4. Queue module can be imported without error
node -e "require('./dist/shared/queue')" 2>&1
# (or use ts-node)
npx ts-node -e "import queue from './src/shared/queue'; console.log('Queue imported OK')"
# Expected: "Queue imported OK"

# 5. BullMQ creates its Redis keys when the worker starts
npm run worker &
sleep 2
redis-cli KEYS "bull:jobs:*" | wc -l
# Expected: at least 1 key
kill %1

# 6. Adding a job to the queue creates a Redis entry
npx ts-node -e "
import queue from './src/shared/queue';
(async () => {
  const job = await queue.add('send-application-confirmation', { test: true });
  console.log('Job id:', job.id);
  await queue.close();
})();
"
# Expected: prints a job id

# 7. Worker processes the job (logs "Processing job" and "Unknown job name")
npm run worker
# Expected output includes:
# [worker] Processing job send-application-confirmation (id: <id>)
# [worker] Unknown job name: send-application-confirmation. Skipping.
# [worker] Job completed: send-application-confirmation (id: <id>)

# 8. Confirm job moved to completed set
npx ts-node -e "
import queue from './src/shared/queue';
(async () => {
  const completed = await queue.getCompleted();
  console.log('Completed count:', completed.length);
  await queue.close();
})();
"
# Expected: Completed count: 1 (or more if you ran the test multiple times)

# 9. package.json has both worker scripts
grep '"worker"' package.json
grep '"start:worker"' package.json
# Expected: both lines present
```

## Quiz

1. `queue.add('send-application-confirmation', payload)` is called in the Express API process.
   `Worker` is running in a separate process. Describe the exact path the job takes through Redis
   from the moment `queue.add` resolves to the moment the worker's handler function is called.

2. The `JobName` union type in `queue.ts` lists every valid job name. What TypeScript feature
   makes this type useful at call sites, and what would you lose if you typed the job name as
   `string` instead?

3. The worker is started with `{ concurrency: 5 }`. Five jobs are added to the queue at the
   same time. Describe what happens in the worker. Then explain what `{ concurrency: 1 }` would
   do differently and when you might prefer it.

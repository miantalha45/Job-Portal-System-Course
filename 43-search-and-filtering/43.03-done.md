## 10. GIN index is used for search queries

```bash
psql $DATABASE_URL -c "
EXPLAIN ANALYZE
SELECT j.id, j.title
FROM jobs j
JOIN companies c ON c.id = j.company_id
WHERE j.status = 'open'
  AND c.status = 'verified'
  AND j.search_vector @@ plainto_tsquery('english', 'engineer')
ORDER BY j.created_at DESC, j.id DESC
LIMIT 20;
"
```

Expected: plan contains `Bitmap Index Scan on idx_jobs_search` or `Index Scan using idx_jobs_search`. No `Seq Scan on jobs` for the full-text condition.

## 1. TypeScript compiles clean

npx tsc --noEmit

## 2. MinIO is running

```bash
curl -s http://localhost:9000/minio/health/live
```

Expected: HTTP 200 (or any non-error response). Alternatively:

```bash
docker compose ps minio
```

Expected: status `running`.

## 3. Bucket exists

```bash
mc ls local/job-portal
```

Expected: command succeeds (no "bucket does not exist" error). If the bucket does not exist, create it:

```bash
mc mb local/job-portal
```

---

## 4. Get a presigned upload URL

```bash
APPLICANT_TOKEN="<access token for applicant with a profile>"

UPLOAD=$(curl -s -X POST http://localhost:3000/api/applicants/profile/resume-upload \
  -H "Authorization: Bearer $APPLICANT_TOKEN" | jq .)
echo $UPLOAD | jq .

UPLOAD_URL=$(echo $UPLOAD | jq -r '.uploadUrl')
KEY=$(echo $UPLOAD | jq -r '.key')
```

Expected: response contains `uploadUrl` (a URL beginning with `http://localhost:9000/job-portal/resumes/...`) and `key` (a string like `resumes/{applicantId}/{uuid}.pdf`).

---

## 5. Upload a file directly to MinIO using the presigned URL

```bash
# Create a dummy PDF for testing
echo "%PDF-1.4 test resume" > /tmp/test-resume.pdf

curl -s -X PUT "$UPLOAD_URL" \
  -H "Content-Type: application/pdf" \
  --data-binary @/tmp/test-resume.pdf \
  -w "%{http_code}"
```

Expected: HTTP 200 from MinIO (no response body — PUT to S3/MinIO returns empty 200 on success).

---

## 6. Confirm the upload

```bash
curl -s -X POST http://localhost:3000/api/applicants/profile/resume \
  -H "Authorization: Bearer $APPLICANT_TOKEN" \
  -H "Content-Type: application/json" \
  -d "{\"key\":\"$KEY\",\"filename\":\"test-resume.pdf\"}" \
  | jq .
```

Expected: HTTP 201, response body contains `id`, `applicant_id`, `filename`, `s3_key`, `uploaded_at`.

## 7. Confirm the object exists in MinIO

```bash
mc ls local/job-portal/resumes/
```

Expected: the object with the matching key appears in the listing.

## 8. Confirm the metadata row is in the database

```bash
psql $DATABASE_URL -c "SELECT id, filename, s3_key, uploaded_at FROM resumes LIMIT 5;"
```

Expected: one row with the key and filename from the upload.

---

## 9. Key spoofing is rejected

```bash
# Attempt to confirm a key that does not belong to this applicant
curl -s -X POST http://localhost:3000/api/applicants/profile/resume \
  -H "Authorization: Bearer $APPLICANT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"key":"resumes/other-applicant-id/evil.pdf","filename":"evil.pdf"}' \
  | jq .
```

Expected: HTTP 403.

---

## 10. Unauthenticated and wrong-role requests are rejected

```bash
# No token
curl -s -X POST http://localhost:3000/api/applicants/profile/resume-upload | jq .
```

Expected: HTTP 401.

```bash
RECRUITER_TOKEN="<recruiter access token>"
curl -s -X POST http://localhost:3000/api/applicants/profile/resume-upload \
  -H "Authorization: Bearer $RECRUITER_TOKEN" | jq .
```

Expected: HTTP 403.

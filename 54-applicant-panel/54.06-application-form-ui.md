# 54.06 — Application Form UI

Build the application action around Chapters 50–53. Display the job and company context above the form so the applicant understands exactly what they are submitting.

Prevent accidental duplicate submission while a request is pending. When the API reports an existing or idempotent application, explain the confirmed state and link to tracking instead of treating it as an unexplained error.

Do not trust a client-side “already applied” flag as the final check.

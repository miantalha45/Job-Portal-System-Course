# 54.09 — Applicant-Page States

For shortlist, application, profile, and tracking pages, deliberately design:

- a first-time empty state;
- a request or upload pending state;
- field validation and safe API errors;
- a confirmed success state;
- a missing or forbidden resource result.

Use the dashboard layout to keep navigation and session feedback consistent, but write messages that explain the specific user task.

# 54.04 — Applicant UI Build Order

Build the applicant experience in this order:

1. public job discovery and a role-aware application entry;
2. shortlist;
3. application form and its result;
4. profile and résumé workflow;
5. application tracking;
6. applicant-specific empty, pending, and failure states.

The public board is expanded in [Chapter 43A](../43a-public-job-board-ui/); do not rebuild its query logic inside the dashboard.

Continue with [54.05 — Shortlist UI](54.05-shortlist-ui.md).

# 54.10 — Verify the Applicant Journey

In a fresh applicant session:

1. Browse public jobs, save one, and remove it.
2. Start an application, submit it, and repeat safely.
3. Edit profile details and exercise the résumé error and success paths.
4. Open the applications page with and without a pending interview.
5. Try applicant-only URLs while signed out and with another role.

Test the same actions by keyboard and at a narrow viewport.

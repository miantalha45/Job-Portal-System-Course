# 54.08 — Application Tracking UI

Start with the applicant-scoped view in Chapter 58: job, company, current stage, submitted date, and next pending interview where available. A stage badge needs adjacent text, not color alone.

Keep application history separate from shortlist. The former records a submitted action; the latter is an optional saved item. Link to [Chapter 58A](../58a-interview-workflow-ui/) for the fuller interview workflow.

Continue with [54.09 — Applicant-page states](54.09-applicant-page-states.md).

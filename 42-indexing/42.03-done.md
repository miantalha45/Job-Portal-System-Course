## 3. Index is used on the public board query

```bash
psql $DATABASE_URL -c "
EXPLAIN ANALYZE
SELECT
  j.id, j.title, j.location, j.employment_type,
  j.salary_min, j.salary_max, j.created_at,
  c.name AS company_name
FROM jobs j
JOIN companies c ON c.id = j.company_id
WHERE j.status = 'open'
  AND c.status = 'verified'
ORDER BY j.created_at DESC, j.id DESC
LIMIT 20;
"
```

Expected: the plan contains `Index Scan using idx_jobs_status_created` (not `Seq Scan on jobs`).

If the table is too small for the planner to choose the index, temporarily disable seq scan to confirm the index would be used:

```bash
psql $DATABASE_URL -c "
SET enable_seqscan = off;
EXPLAIN ANALYZE
SELECT j.id, j.title, j.created_at, c.name AS company_name
FROM jobs j
JOIN companies c ON c.id = j.company_id
WHERE j.status = 'open' AND c.status = 'verified'
ORDER BY j.created_at DESC, j.id DESC
LIMIT 20;
SET enable_seqscan = on;
"
```

Expected: `Index Scan using idx_jobs_status_created` appears in the plan.

# 43A.09 — Make the Board Responsive and Accessible

Check the list at a narrow phone width, a medium tablet width, and a wide desktop width. Search controls should reflow before text or action targets become cramped.

Test keyboard tab order, visible focus, heading hierarchy, filter labels, and sufficient contrast. Announce or focus the results region after a submitted search.

# 43A.10 — Walk the Public Journey

In a browser:

1. Open `/jobs` with no parameters.
2. Search and filter, then copy the URL into a new tab.
3. Follow a job card to its detail page.
4. Use the application call to action while signed out and as each role.
5. Try a result set with no matches and a no-longer-public job URL.

Fix any point where the visitor cannot tell what happened or what to do next.

# 43A.06 — Add Cursor Navigation

Use the `nextCursor` (and previous cursor if supplied) returned by Chapter 41. Keep it in the query string rather than inventing a numbered page from the visible array.

The “next results” control is disabled or omitted when the API says no cursor remains. Moving between result sets should update the visible result count and move focus to the results heading so screen-reader users know content changed.

# 43A.04 — Build the Search and Filter Form

Use a real `<form>` with a visible submit control. Labels must name every search field; placeholders are hints, not labels. Add a “clear filters” link that returns to the bare `/jobs` URL.

Show active filters in plain text above the results. On small screens, the form may collapse into a panel, but keyboard users must still be able to open it, change values, submit, and close it.

# Chapter 43A — Public Job-Board UI

Chapters 39, 41, and 43 provide the public-job data, cursor pagination, and search/filter contract. This chapter turns that contract into an accessible Next.js experience without duplicating filtering rules in the browser.

## Prerequisites

- [Chapter 4A — Frontend Foundations](../04a-frontend-foundations/)
- Chapters 39, 41, and 43

Build the public pages before applicant-only actions. A visitor should be able to discover an open job, understand it, and reach the appropriate application path without signing in.

Continue with [43A.02 — Map public routes](43a.02-public-route-map.md).

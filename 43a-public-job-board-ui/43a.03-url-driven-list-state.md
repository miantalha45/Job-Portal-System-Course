# 43A.03 — Read List State From the URL

Read search text, location, job type, and any other Chapter 43 filters from `searchParams` on the server. Pass only recognized values to the API helper and normalize absent values to the documented defaults.

The URL becomes shareable and Back-button friendly. Filter controls update query parameters, which causes the server-rendered list to request the authoritative filtered result.

Reset the pagination cursor whenever a filter changes.

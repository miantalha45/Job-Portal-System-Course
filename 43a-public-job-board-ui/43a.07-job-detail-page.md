# 43A.07 — Build the Job-Detail Page

Render the job’s title, company, location, structured description, requirements, and application call to action. Use a server-rendered not-found state when the API reports a missing, closed, or non-public job.

The primary action must reflect session state without becoming an authorization decision:

- signed-out visitor: sign in or register to apply;
- applicant: continue to the application flow;
- recruiter or admin: explain that the applicant flow is unavailable for their role.

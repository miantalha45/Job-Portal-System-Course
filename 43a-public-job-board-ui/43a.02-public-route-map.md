# 43A.02 — Map the Public Routes

Keep public browsing in two stable routes:

| Route | Purpose |
|---|---|
| `/jobs` | Searchable, filterable list of open jobs |
| `/jobs/[id-or-slug]` | One job’s complete public detail |

Use the public identifier supported by the API. Do not expose draft, closed, or company-internal data merely because a person can guess an ID.

The list owns filter state in the URL; the detail page owns the call to action.

Continue with [43A.03 — Read list state from the URL](43a.03-url-driven-list-state.md).

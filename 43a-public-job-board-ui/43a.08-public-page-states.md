# 43A.08 — Cover Public Page States

Design all four list outcomes:

| Outcome | UI response |
|---|---|
| Loading | predictable skeleton or loading message |
| Results | count, active filters, usable list |
| No results | state the filters and offer clear filters |
| API failure | explain that jobs could not load and offer retry |

Ensure a job description is safely rendered as content, not injected HTML from the API.

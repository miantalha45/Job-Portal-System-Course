# 61.07 — Job Moderation UI

Build the job review page from Chapter 60’s administrator-scoped list and actions. Show title, company, present lifecycle status, and enough context to make the permitted moderation decision.

Separate public visibility from an internal action control. A job that an admin may close is not necessarily a record that should be rendered in a public route.

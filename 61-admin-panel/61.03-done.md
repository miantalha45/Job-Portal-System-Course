# Chapter 61 — Definition of Done

## Verifiable checklist

```bash
# 1. TypeScript compiles (Next.js project)
cd frontend && npx tsc --noEmit

# 2. Start both the API and the Next.js dev server
# Terminal 1:
npm run dev              # Express API on :3000
# Terminal 2:
cd frontend && npm run dev   # Next.js on :3001

# 3. Visit /admin/companies as a non-admin — expect redirect to /
# (Log in as a recruiter, then navigate to http://localhost:3001/admin/companies)
# Browser should redirect to http://localhost:3001/

# 4. Log in as admin and visit /admin/companies — expect the companies table
# Navigate to http://localhost:3001/admin/companies in the browser
# Confirm the table renders with columns: Name, Status, Owner, Created, Actions

# 5. Click the Verify button on a pending company
# Confirm the page re-renders and the company status changes to "verified"
# Confirm the Verify button is now disabled for that row

# 6. Click the Suspend button on a verified company
# Confirm the page re-renders and status changes to "suspended"

# 7. Visit /admin/companies?status=pending
# Confirm only pending companies appear in the table

# 8. Visit /admin/jobs — expect a jobs table with Close buttons
# Click Close on an open job
# Confirm the job status changes to "closed" and the button becomes disabled

# 9. Visit /admin/users — expect a users table
# Click Suspend on a non-admin user
# Confirm the status changes to "suspended"
# Click Activate on the same user
# Confirm the status changes to "active"

# 10. Confirm the admin panel works without JavaScript disabled in the browser
# (Forms with Server Actions submit via standard HTML POST — no JS required)
# In Chrome: DevTools → Network → disable JS → repeat step 6 → confirm it still works

# 11. Confirm no admin route is accessible without a valid admin token
curl -s -o /dev/null -w "%{http_code}" \
  http://localhost:3000/api/admin/companies
# Expected: 401 (no token)

curl -s -o /dev/null -w "%{http_code}" \
  -H "Authorization: Bearer $NON_ADMIN_TOKEN" \
  http://localhost:3000/api/admin/companies
# Expected: 403
```

## Quiz

1. The layout fetches `GET /api/auth/me` with `cache: 'no-store'` on every request. What would
   happen if you removed that option and Next.js cached the response? Give a specific scenario
   where this causes a security problem.

2. A Server Action calls `revalidatePath('/admin/companies')` after a mutation. What does
   `revalidatePath` do, why is it necessary here, and what would the user see if you forgot it?

3. The Verify and Suspend buttons are disabled in the UI when the action would have no effect.
   A security engineer says the UI check is not sufficient. What is the correct statement about
   where the authoritative check lives, and how does the system enforce it even if someone
   bypasses the frontend?

# 61.10 — Verify the Admin Panel

Test with an admin and a non-admin:

1. Review and act on a company, a job, and a user using permitted actions.
2. Refresh after each mutation and confirm the server result remains visible.
3. Open each admin URL as a recruiter and applicant.
4. Trigger a validation or network failure and confirm the record does not falsely appear updated.
5. Review the page at phone width and by keyboard.

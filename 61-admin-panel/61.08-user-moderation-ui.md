# 61.08 — User Moderation UI

Use the role, account state, and actions defined by Chapter 60. Make the selected person, intended action, and likely consequence visible before submission.

Do not allow an editable text field to invent roles or account states. Render only the transitions the backend accepts and return to a refreshed server result when a mutation completes.

Continue with [61.09 — Admin action feedback](61.09-admin-action-feedback.md).

# 61.05 — Admin Dashboard Shell

Use a protected admin layout with clear navigation to companies, jobs, and users. The route verifies the trusted session and role on the server before rendering sensitive data.

Give the layout an unmistakable admin heading so a person does not confuse moderation controls with their recruiter dashboard. Include a visible sign-out action and keyboard-friendly navigation.

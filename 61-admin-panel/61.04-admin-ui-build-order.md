# 61.04 — Admin UI Build Order

Treat moderation as a set of distinct decisions, not one giant table:

1. protected admin shell;
2. company review;
3. job review;
4. user review;
5. mutation feedback and an audit-friendly verification pass.

The browser can reduce mistakes with clear UI, but Chapters 59–60 retain all authority to approve, suspend, activate, or close.

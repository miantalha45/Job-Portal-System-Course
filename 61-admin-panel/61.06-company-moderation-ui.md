# 61.06 — Company Moderation UI

Render the company data and review status supplied by Chapter 59. Surface the information an admin needs to make a decision, then make approve, suspend, or other allowed actions explicit and pending-aware.

Never hide a failed mutation behind an optimistic badge. Refresh the authoritative record and show the returned status. Use confirmation for actions that disable a company’s ability to operate.

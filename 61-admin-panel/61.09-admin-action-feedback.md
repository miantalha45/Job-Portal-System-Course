# 61.09 — Admin Action Feedback

All moderation pages need four clear responses:

| Response | UI expectation |
|---|---|
| Pending | Identify the record and action in progress |
| Succeeded | Show the refreshed server state |
| Rejected | Preserve context and explain the safe failure |
| Forbidden/session ended | Leave the restricted area without exposing data |

If the system records audit details, show only the fields the API explicitly authorizes for this panel.

Continue with [61.10 — Verify the admin panel](61.10-admin-panel-check.md).

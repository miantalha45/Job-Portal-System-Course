# 74A.07 — Test Components and Helpers

Add focused tests for high-value, deterministic behavior:

- formatting and query-parameter helpers;
- client form validation and pending states;
- reusable status, empty, and error components;
- role-aware navigation decisions made from trusted supplied session data.

Use the test runner already chosen for the frontend. Test user-visible behavior and accessible roles/text rather than internal class names or component implementation details.

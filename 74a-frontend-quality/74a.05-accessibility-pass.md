# 74A.05 — Run an Accessibility Pass

Check each main journey with a keyboard:

1. Every control receives a visible focus indicator.
2. Modals, menus, and panels can be opened and closed predictably.
3. Forms have labels, errors, and error summaries.
4. Dynamic results and mutation outcomes are announced or focused.
5. Meaning is not communicated by color, shape, or position alone.

Use automated accessibility checks as a prompt, then make the final judgment in the actual browser.

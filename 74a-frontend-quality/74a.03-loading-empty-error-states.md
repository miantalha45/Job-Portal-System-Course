# 74A.03 — Fill State-Coverage Gaps

Every data route should communicate one of these outcomes:

- loading or pending;
- useful data;
- an empty result with a next action;
- a recoverable request failure;
- missing or forbidden data.

Create shared presentational components only where the message and interaction are genuinely the same. A generic “something went wrong” screen is not enough for a job search, a rejected mutation, and a missing job.

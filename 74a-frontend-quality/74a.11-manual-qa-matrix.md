# 74A.11 — Complete the Manual QA Matrix

Check the finished project in a clean browser session:

| Check | Pass condition |
|---|---|
| Visitor flow | Jobs are discoverable and detail pages are understandable |
| Applicant flow | Apply, profile, and tracking states are clear |
| Recruiter flow | Job and candidate mutations give reliable feedback |
| Admin flow | Restricted actions remain role-scoped |
| Failure flow | No raw errors, stale success states, or dead-end pages |
| Device flow | Core tasks work on narrow and wide screens |

Write down known limitations rather than silently treating them as complete.

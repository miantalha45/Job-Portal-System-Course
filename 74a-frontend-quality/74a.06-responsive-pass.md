# 74A.06 — Run a Responsive Pass

Inspect public, applicant, recruiter, and admin screens at a narrow phone, medium tablet, and wide desktop width. Test zoom as well as viewport width.

Look for horizontal overflow, clipped error messages, tiny targets, inaccessible off-canvas navigation, tables that hide essential information, and side-by-side forms that cannot reflow. Prioritize readable content and operations over preserving a desktop layout.

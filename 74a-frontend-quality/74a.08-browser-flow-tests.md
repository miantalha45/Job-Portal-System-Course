# 74A.08 — Test the Main Browser Flows

Use a browser test tool if the project has one, or record a repeatable manual script if it does not. Cover at least:

- public search to job detail;
- sign-in to the correct role dashboard;
- applicant application tracking;
- recruiter stage change and interview scheduling;
- an unauthenticated attempt at a protected route.

Prepare predictable seed data. Browser tests should prove the integration between browser, Next.js, and Express, not replace API tests.

# 74A.10 — Review Browser Performance Basics

Avoid performance work that complicates the learning project. First remove obvious waste:

- render data on the server when no client interaction is needed;
- keep client components narrow;
- avoid duplicate API requests for the same route;
- give images explicit dimensions and useful alt text;
- keep loading feedback visible when a request legitimately takes time.

Measure before introducing memoization, caching layers, or another state library.

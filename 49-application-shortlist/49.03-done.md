## 9. IDOR check — applicant cannot remove another applicant's shortlist item

```bash
# As applicant A, shortlist a job
APPLICANT_A_TOKEN="<applicant A token>"
curl -s -X POST http://localhost:3000/api/applicants/shortlist \
  -H "Authorization: Bearer $APPLICANT_A_TOKEN" \
  -H "Content-Type: application/json" \
  -d "{\"jobId\":\"$JOB_ID\"}" > /dev/null

# As applicant B, attempt to delete applicant A's shortlist item by guessing the jobId
APPLICANT_B_TOKEN="<applicant B token>"
curl -s -X DELETE "http://localhost:3000/api/applicants/shortlist/$JOB_ID" \
  -H "Authorization: Bearer $APPLICANT_B_TOKEN" \
  | jq .
```

Expected: HTTP 404 — applicant B has no such item in their shortlist. Applicant A's item is unaffected.

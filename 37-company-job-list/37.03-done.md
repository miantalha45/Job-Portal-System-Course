## 2. Setup: create several jobs

Use the owner token from previous chapters. Create at least 5 jobs with a mix of statuses.

```bash
RECRUITER_TOKEN=$(curl -s -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"owner@example.com","password":"Password1!"}' \
  | jq -r '.accessToken')

for i in 1 2 3 4 5; do
  curl -s -X POST http://localhost:3000/api/jobs \
    -H "Authorization: Bearer $RECRUITER_TOKEN" \
    -H "Content-Type: application/json" \
    -d "{\"title\": \"Job $i\", \"employment_type\": \"full_time\"}" \
    | jq -r '.jobId'
done
```

Publish two of them:

```bash
JOB1="<uuid-of-first-job>"

  -H "Authorization: Bearer $RECRUITER_TOKEN" | jq .
```

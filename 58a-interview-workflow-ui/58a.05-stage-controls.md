# 58A.05 — Add Stage Controls

Represent allowed stage changes as labelled controls, not an unrestricted text field. Before submit, show the candidate name, current stage, and intended stage. Disable the triggering control while the request is pending.

After the API confirms success, refresh the pipeline and detail data. If it rejects the change, retain the original server state and show its safe explanation; do not optimistically claim success.

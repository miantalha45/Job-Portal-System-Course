# 58A.08 — Build Applicant Tracking

Render the applicant’s Chapter 58 list as a timeline or chronological cards. For each application, show job title, company, current stage, submitted date, and the next pending interview when one exists.

Use considerate language for rejected and inactive applications. Applicants see their own tracking data only; the browser must never infer visibility by filtering a company-wide response.

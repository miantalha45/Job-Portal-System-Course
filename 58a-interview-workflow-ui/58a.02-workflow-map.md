# 58A.02 — Map the Workflow

Map the reader’s two perspectives before coding:

| Recruiter | Applicant |
|---|---|
| Find candidate in a company/job pipeline | See current application stage |
| Advance or reject the application | Understand the next step |
| Schedule and review interviews | See the next pending interview |
| Record feedback/outcome | See a clear post-interview status |

Use the stage vocabulary from Chapter 55 exactly. The UI may add explanatory copy, but it must not create a new stage that the API does not recognize.

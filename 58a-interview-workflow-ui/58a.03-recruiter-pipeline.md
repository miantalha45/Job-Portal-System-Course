# 58A.03 — Build the Recruiter Pipeline

Render the grouped response from Chapter 58 as stage columns or as an accessible grouped list. Each group must state its stage and candidate count; each candidate item links to a fuller application view.

Start with a responsive list that stacks naturally on narrow screens. If you later add drag-and-drop, preserve keyboard controls and retain a button-based alternative.

# 58A.09 — Cover Workflow States

Add deliberate UI for:

| Case | Needed feedback |
|---|---|
| Empty pipeline stage | No candidates are at this step yet |
| No applications | Explain how to browse or apply |
| Pending mutation | Identify the candidate and action in progress |
| Validation/permission failure | Keep data and give a safe next action |
| Network failure | Explain that the server state is unknown and refresh |

Use status text and icons together, not color alone.

Continue with [58A.10 — Verify the workflow](58a.10-workflow-check.md).

# 58A.04 — Build Candidate Application Details

Create a recruiter-only detail view for one application. It should assemble the snapshot headline, job context, present stage, résumé action when authorized, and latest or upcoming interview from the established APIs.

Make the source of each fact clear: an application snapshot preserves what was applied for; a job page may have changed later. Avoid silently replacing snapshot values with current job values.

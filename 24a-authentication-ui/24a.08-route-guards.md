# 24A.08 — Guard Browser Routes

Use the shared server-side session helper at protected layouts. It should distinguish:

- no session: redirect to sign-in;
- session but wrong role: show a permission-safe page or redirect to that role’s dashboard;
- valid session: render the requested area.

Middleware may provide a quick redirect, but it is not the authorization boundary. Never trust a role value supplied by a Client Component.

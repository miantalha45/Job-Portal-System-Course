# 24A.11 — Quick Quiz

1. Why should a login page not decide that a user is an admin?
2. Where should a browser-facing access token live in this course?
3. What should happen when a user opens a protected route with no session?

Answers: authorization belongs to trusted server and API checks; use the httpOnly-cookie flow; redirect to sign-in with a safe return path.

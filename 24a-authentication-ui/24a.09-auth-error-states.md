# 24A.09 — Design Authentication Failure States

Create intentional UI for expired sessions, malformed requests, rate limits, network failures, and access denial. Each state should say what happened in plain language and offer one useful recovery action.

Use the same error shape throughout the frontend. Avoid displaying raw backend stack traces, token content, or whether a particular email address exists.

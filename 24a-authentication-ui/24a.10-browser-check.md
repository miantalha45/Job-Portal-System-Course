# 24A.10 — Check the Journey in a Browser

Run this sequence with a fresh browser profile:

1. Register and inspect the confirmation state.
2. Verify the account using a valid and an invalid token.
3. Sign in as each available role and confirm the correct dashboard destination.
4. Open a protected URL while signed out and confirm the sign-in redirect.
5. Sign out, then use the browser Back button and confirm protected data is not revealed.

Record every confusing message before moving on.

# 24A.06 — Choose the Dashboard Entry

Create one small, server-rendered dashboard entry route. It asks the trusted session helper for the current user and directs them to the appropriate area:

| Role | Destination |
|---|---|
| Applicant | applicant dashboard |
| Recruiter or company member | company dashboard |
| Admin | admin dashboard |

The destination improves navigation only. Every downstream page and API request must still perform its own authorization check.

# 24A.02 — Map the Authentication Journey

List the pages before styling them:

| State | Route | Reader can do |
|---|---|---|
| New visitor | `/register` | Create an account |
| Returning visitor | `/login` | Start a session |
| Unverified account | `/verify-email` | Submit or consume the verification token |
| Signed-in user | `/dashboard` | Continue to the correct role area |
| Signed-out user | public routes | See confirmation and sign in again |

Keep a `next` destination only when it is an internal, validated application path. A failed request stays on its page and explains the next useful action.

# 24A.07 — Add a Logout Action

Place logout in the authenticated navigation, not on a hidden utility route. It calls the session-clearing endpoint or proxy, clears cookies on the server response, and returns the visitor to a public page.

If logout fails because the server session is already gone, treat the browser as signed out after the cookies are safely cleared. The control needs a pending state so duplicate clicks cannot race.

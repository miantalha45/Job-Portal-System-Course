## 2. Setup: seed open jobs from a verified company

You need at least two published jobs from a verified company. Use your existing recruiter token (owner account).

```bash
# Log in as recruiter
RECRUITER_TOKEN=$(curl -s -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"owner@example.com","password":"Password1!"}' \
  | jq -r '.accessToken')

# Create two jobs and publish them
JOB_A=$(curl -s -X POST http://localhost:3000/api/jobs \
  -H "Authorization: Bearer $RECRUITER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"title":"Backend Engineer","description":"Build APIs in TypeScript","location":"Remote","employment_type":"full_time","salary_min":100000,"salary_max":140000}' \
  | jq -r '.jobId')

JOB_B=$(curl -s -X POST http://localhost:3000/api/jobs \
  -H "Authorization: Bearer $RECRUITER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"title":"DevOps Engineer","description":"Manage cloud infra","location":"New York","employment_type":"contract","salary_min":90000,"salary_max":120000}' \
  | jq -r '.jobId')

curl -s -X POST http://localhost:3000/api/jobs/$JOB_A/publish \
  -H "Authorization: Bearer $RECRUITER_TOKEN" | jq .

curl -s -X POST http://localhost:3000/api/jobs/$JOB_B/publish \
  -H "Authorization: Bearer $RECRUITER_TOKEN" | jq .
```

Also confirm the company is verified:

```bash
psql $DATABASE_URL -c \
  "SELECT name, status FROM companies WHERE status = 'verified';"
```

Expected: at least one verified company row.
